# ADR 0005 Typed static i18n plus versioned dynamic translations

Status: Accepted

Static application keys live in equal `uz-Latn`, `ru`, and `en` bundles and are exposed through a typed translator. Dynamic journal content and notification templates are immutable published database versions with atomic three-locale publication.

Fallback is exact locale, then `uz-Latn`, then a safe universal message. Missing production keys or placeholder mismatch fails CI; raw keys are never displayed.
