# Code of conduct

Project collaboration must remain respectful, professional, and focused on building a safe journal-submission service.

Harassment, discrimination, threats, publication of private information, credential sharing, and attempts to pressure contributors into bypassing security or review controls are not acceptable. Technical disagreement is welcome when it addresses evidence and requirements rather than people.

Report conduct concerns privately to the repository owner. Reports will be reviewed confidentially and may result in content removal, participation restrictions, or blocking. This policy applies to repository issues, pull requests, reviews, discussions, and project-related communication.
